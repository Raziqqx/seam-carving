# Decisions log

**Reconstructed on 20 Nov 2026.** During the project the team kept a shared decisions log of
what the AI got right, what it got wrong and what we decided to do about it. The original
was lost together with the AI session it was kept alongside. This file rebuilds it from
the sources that survived: the git history, the pull requests, the review reports and the
CI runs. Commit hashes and PR numbers point to the evidence; entries from before the first
push (16–17 Nov) come from the review reports, as those commits were squashed into the
milestone commits.

## Decisions made before the build

| # | Decision | Why |
|---|---|---|
| D1 | C++17 + CMake, OpenCV only for image input and output, colour conversion, the Sobel filter, scaling (baseline) and video | The brief allows image libraries but no content-aware resizing; keeping OpenCV at the edges means every seam algorithm is our own code |
| D2 | Our own Edmonds-Karp max-flow; Boost's max-flow only inside one test, as an independent cross-check | The brief asks us to solve the cut ourselves; a second solver catches bugs in ours |
| D3 | Readability rule: clear names, short functions, a comment with purpose and complexity on every core function, plain versions kept next to optimised ones | Closed-book quiz on our own code; every member must be able to explain every function |
| D4 | Every number in the report is generated by a script (`benchmarks/run_all.sh` → `report/generated/facts.txt`) | No typed-in numbers that can go stale or be wrong |
| D5 | Tests compare DP with brute force over all seams, graph cut with DP and with Boost, greedy with DP | Correctness is shown by independent methods, not by trusting one implementation |
| D6 | Six milestones, one per member, matching the six presentation sections; each on its own branch, merged through a pull request with CI | Each member owns and presents the part they worked on |
